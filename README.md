# ☁️ Cloud Expense Tracker

A simple and responsive **Cloud-Based Expense Tracker** developed using HTML, CSS, JavaScript, and Firebase Realtime Database.

The application allows users to add, view, edit, delete, and search expenses. All expense data is stored in the **Firebase Realtime Database**, making the application cloud-based.

---

## 🚀 Features

-  Add new expenses
-  Edit existing expenses
-  Delete expenses
-  Search expenses
-  Calculate total expenses
-  Display number of transactions
-  Calculate average expense
-  Store expense dates
-  Categorize expenses
-  Store data in Firebase Realtime Database
-  Responsive design for different screen sizes

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Firebase Realtime Database
- Firebase JavaScript SDK
- GitHub

---

## ☁️ Cloud Technology

This project uses **Firebase Realtime Database** as its cloud backend.

When a user adds an expense, the information is sent from the web application to Firebase and stored in the cloud.
